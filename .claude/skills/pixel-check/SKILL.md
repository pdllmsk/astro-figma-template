# pixel-check

Блок считается готовым, только когда его скриншот совпадает с Figma. «На глаз» не годится.

Скрипт: `.claude/skills/pixel-check/pixel_check.py` (Python 3.11 с playwright, pillow, numpy — они уже стоят).
Результаты пишутся в `.ca-workflow/pixel-check/<block>-<ширина>/` (в git не попадает).

## 1. Подготовка

1. Дев-сервер: `preview_start {name: "dev"}`. Взять порт из ответа.
2. Из `.ca-workflow/workflow.md`: ключ файла, ширины фреймов и ноды блока на каждом фрейме. N — порядковый номер блока на странице (таблица блоков, без Header и Footer).
   Селектор блока: `main > section:nth-of-type(N)`. Header — `[data-header]` (с `--hide ""`), Footer — `body > footer`.
3. Сверка — на каждом фрейме, где у блока есть node. Для каждой ширины W — скриншот Figma в масштабе 1:
   `get_screenshot {fileKey, nodeId, maxDimension: 4000}`. Затем скачать по `curl -f -L -o .ca-workflow/pixel-check/<block>-W/figma.png "<url>"`.
   Проверить, что `width` в ответе = W. Если нет — поднять `maxDimension`.

## 2. Прогон

```bash
python3.11 .claude/skills/pixel-check/pixel_check.py --url http://localhost:<port>/ --width W --selector "main > section:nth-of-type(N)" --figma .ca-workflow/pixel-check/<block>-W/figma.png --out .ca-workflow/pixel-check/<block>-W
```

Скрипт открывает страницу на ширине W с DPR 1. Он отключает анимации, прячет фиксированную шапку, ждёт шрифты и картинки, а потом печатает:

- `figma_size` / `impl_size` — размеры блока;
- `mismatch_pct` — доля несовпавших пикселей;
- `first_bad_row` — первая строка, где расхождение больше 2% ширины.

Кроме того, он сохраняет:

- `compare.png` — Figma | вёрстка | diff (красное = не совпало);
- `texts.tsv` — каждый текст блока: `y x h w size lh ls weight font text`, координаты в px от левого верхнего угла блока.

## 3. Разбор — строго по порядку

**A. Размер.** Если `impl_size` ≠ `figma_size`, расхождение где-то набегает. Найти первое место по `first_bad_row` и `compare.png` (смотреть кропом этой зоны, а не всю картинку). Исправить и прогнать заново. Пока размер не совпал, остальные шаги не делать.

**B. Типографика** (здесь ломается чаще всего). Из `get_design_context` блока выписать для каждого текста кегль, line-height и letter-spacing. Сверить с `size`, `lh`, `ls` в `texts.tsv`:

- letter-spacing в Figma задан в % → px = кегль × % / 100;
- line-height «auto» в Figma ≠ `normal` в браузере, нужно явное значение;
- значения должны совпадать точно; если нужного `Text variant` нет — добавить токен и вариант (AGENTS.md), а не брать ближайший.

**C. Положение строк.** Для каждого текста из `texts.tsv` найти слой с тем же текстом в `get_metadata` блока. Посчитать его координаты от верха блока (сложить `x`/`y` всех родителей до фрейма блока) и сравнить с `y`, `x`, `h`. Если |Δ| > 1px:

- `h` совпадает, `y` нет → неверный отступ или gap выше: исправить в `Stack`, значение взять из макета (нет в `SPACE` — добавить);
- `h` и `y` совпадают, а в `compare.png` буквы внутри строки сдвинуты по вертикали → это метрики шрифта, отступами такое не лечится. Исправлять в `@font-face` через `ascent-override` / `descent-override` / `line-gap-override` для этого шрифта: один раз для всех блоков. Если сомневаешься, остановиться и показать пользователю кроп.

**D. Остальное красное в diff** — картинки (кадрирование, размер), декор, рамки. Сверить с размерами слоёв в `get_metadata`.

После каждой правки — повторный прогон.

## 4. Готово, когда

- `impl_size` = `figma_size`;
- все тексты: `size`, `lh`, `ls` точно как в Figma; `y`/`x` в пределах 1px;
- `mismatch_pct` ≤ 1% (сглаживание шрифтов и сжатие картинок дают шум; если выше — показать пользователю кроп оставшихся зон и сказать, почему не убрано).

В отчёте пользователю: `mismatch_pct` до и после, что исправлено, что осталось и почему.
